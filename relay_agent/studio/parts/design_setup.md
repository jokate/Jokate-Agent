## 세팅 바꾸기

1. 바꾸기 전에 사양(작업의 사양 · `Docs/`)에서 넣을 값을 확인한다. 사양에 없는 값은 지어내지 않고 묻는다.
2. 대상 애셋의 지금 값을 MCP 로 읽어 적어 둔다.
3. MCP 로 값을 바꾸고 저장한다. 애셋 파일을 파일 도구로 직접 건드리지 않는다.
4. 바꾼 뒤 다시 읽어 값이 들어갔는지 확인한다.
5. 바꾼 애셋의 경로와 전 · 후 값을 적는다.

- unreal MCP 가 붙지 않았거나 에디터가 응답하지 않으면 멈추고 알린다. 다른 방법으로 돌아가지 않는다.
- GameplayTag 는 추가하기 전에 같은 뜻의 태그가 있는지 찾는다.
- 프로젝트 설정은 바꾼 항목과 이유를 적는다.
